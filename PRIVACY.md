# Privacy Policy

_Last updated: 24 September 2026_

Platypus ("the application") is a personal tool operated by its author for his own use. It
has one user. It is not offered to the public and collects nothing from anyone else.

## What the application accesses

With the user's permission, the application uses the Google Drive API under the `drive.file`
scope. That scope grants access only to files the application itself creates in the user's
Google Drive. It cannot see, read, or modify any other file or folder in that Drive.

## What it does with that access

- Uploads daily report files generated on the user's own computer, which Google Drive
  converts into Google Docs.
- Removes older copies of reports it previously uploaded under the same name, so one copy
  per day remains.

That is the full extent of its use of Google user data.

## What it does not do

- It does not read files it did not create.
- It does not collect, store, or transmit personal information.
- It does not share, sell, or transfer any data to third parties.
- It does not use Google user data for advertising, profiling, or training any model.
- It has no analytics and no server; it runs entirely on the user's own machine.

## Credentials

OAuth credentials are stored locally on the user's own computer, in a file excluded from
version control. They are not transmitted anywhere except to Google's own authentication
endpoints.

## Retention and deletion

Documents created by the application remain in the user's Google Drive until the user
deletes them. Access can be revoked at any time at https://myaccount.google.com/permissions
